How It Works

Drop. Double-click. Diagnose.

No installers. No dependencies. No cloud accounts required. Just copy two files to a USB stick.

1

Copy to USB

Drag SentinelRecon.Portable.ps1 and .bat onto any USB stick. That's it.

2

Double-click

On any Windows 10/11 box, double-click the .bat. It self-extracts to %TEMP% and launches the web console on port 8080.

3

Run Diagnostics

Pick any tool from the catalog -- 89 scripts across 15 categories. Results come back as structured JSON with scored checks.

▶ Run: Full Security Audit
Score: 85/100 -- 17/20 checks passed
